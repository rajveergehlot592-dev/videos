YouTube Creator Automation

VicePulse Uploader

VicePulse Uploader is the official publishing tool for the VicePulse YouTube channel (@VicePulseTV99). It automates preparing, scheduling, and uploading 1080p60 vertical Shorts and metadata directly to YouTube via the official YouTube Data API v3.

What This Application Does

  • Uploads portrait 1080×1920 Shorts created in the GTA VI Clip Factory pipeline.
  • Applies optimized titles, descriptions, hashtags, and scheduled publish timestamps.
  • Requests only the authorized YouTube upload scope needed to publish to the creator's channel.
