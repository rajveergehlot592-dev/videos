## 2. Project Structure & Key Files
- **`gta6_clip_factory/`** — Full-stack FastAPI + React/Vite Studio (`http://127.0.0.1:8000/`):
  - `backend/main.py` — API server, manifest persistence, batch export queue, static UI serving
  - `backend/youtube_ingest.py` — Direct YouTube URL & livestream 1080p60 extraction + community highlight parsing
  - `backend/youtube_uploader.py` — Official YouTube Data API v3 scheduled uploader (`videos.insert` + `thumbnails.set`)
  - `backend/analyzer.py` — Multi-signal `0.5s` local highlight detector (audio RMS/MAD, motion, scene changes, `.srt`)
  - `backend/renderer.py` — 3-layout (`blurred_bg`, `dynamic_crop`, `manual_crop`) 1080×1920 H.264/AAC renderer + Pro VO/SFX mode
  - `backend/media_probe.py` — `ffprobe` + `ffmpeg -i` fallback probing
  - `frontend/src/App.jsx` — 3-column Vice City Neon Studio UI with direct YouTube URL bar, 9:16 phone player, and render queue
  - `install.bat`, `start.bat`, `diagnostics.bat`, `tests/test_clip_factory.py`
- **`IShowSpeed_PRO_REELS/`** — 10 finished 1080p60 copyright-safe Pro Reels (`Speed_Reel_001..010.mp4`), viral hook thumbnails, and `METADATA/youtube_upload_details.csv`
- **`TECHNO_GAMERZ_PRO_REELS/`** — 6 finished 1080p60 Pro Reels (`Pro_Techno_Reel_001, 004, 006, 008, 014, 016.mp4`) + thumbnails
